# FAQ-бот хакатона

Простой терминальный бот на Python. Он отвечает на вопросы о времени проведения,
команде, треке, сдаче решения и призах. **Условия хакатона в FAQ демонстрационные:**
перед использованием замените их на реальные.

Бот приводит запрос к нижнему регистру, заменяет «ё» на «е», фильтрует шум
и сравнивает слова с ключевыми корнями и вопросами из FAQ (включая нечёткий поиск
по `difflib` для устойчивости к опечаткам). Ответ выбирается по максимальному весу
совпадений. При отсутствии совпадений выводится `Не знаю`. Решение не требует
внешних библиотек, API-ключей или RAG.

## Структура

```text
.
├── bot.py       # Чтение FAQ, поиск ответа и ввод в терминале
├── faq.txt      # 5 вопросов с ответами и ключевыми словами
├── README.md    # Описание и запуск
└── .gitignore   # Исключения для Git
```

## Требования и запуск

Нужен Python 3.8 или новее. Используется только стандартная библиотека;
установка пакетов, API-ключи и интернет не нужны. OpenAI API, RAG и embeddings
не используются. Откройте терминал в папке проекта и выполните:

```bash
python bot.py
```

Для выхода введите `exit`, `выход` или `quit` (регистр не важен). Также можно нажать `Ctrl+C`.
Файл FAQ читается в UTF-8 из папки скрипта, независимо от текущей папки терминала.

## Пример работы

```text
Вы: Когда проходит хакатон?
Бот: Хакатон проходит с 10:00 до 18:00 и длится один день.
Вы: Во сколько старт?
Бот: Хакатон проходит с 10:00 до 18:00 и длится один день.
Вы: Сколько человек в команде?
Бот: В команде может быть от 1 до 4 человек. Можно участвовать одному.
Вы: Что дают победителям?
Бот: Победители получат дипломы и подарки, а все участники — сертификаты.
Вы: Будет награда?
Бот: Победители получат дипломы и подарки, а все участники — сертификаты.
Вы: Какая погода завтра?
Бот: Не знаю
Вы: выход
Бот: До встречи!
```

Чтобы изменить FAQ, отредактируйте `faq.txt`. Поддерживается как стандартный формат
`вопрос | ответ`, так и расширенный `вопрос | ответ | ключи через пробел`. Ключи
пишутся строчными буквами, с «е» вместо «ё»; можно указывать основы слов (например,
`наград` распознает «награда» и «награды»). Опечатки обрабатываются автоматически.
Не используйте символ `|` внутри вопроса или ответа.
